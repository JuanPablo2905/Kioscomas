# Instalar Kiosco+ en Mac

Hay dos instaladores para evitar demoras y fallos en la publicación:

- `KioscoPlus-Mac-arm64.dmg`: Mac con chip Apple M1, M2, M3, M4 o posterior.
- `KioscoPlus-Mac-x64.dmg`: Mac con procesador Intel.

Para comprobarlo, abrí el menú Apple  y elegí **Acerca de esta Mac**. Si dice **Chip Apple**, descargá Apple Silicon. Si dice **Procesador Intel**, descargá Intel.

## Instalación

1. Descargá el archivo DMG correspondiente desde la página de Kiosco+ o desde la última versión publicada en GitHub.
2. Abrí el DMG.
3. Arrastrá **Kiosco+** a la carpeta **Aplicaciones**.
4. Expulsá el instalador y abrí Kiosco+ desde Aplicaciones.

## Primera apertura sin firma de Apple

Mientras la aplicación no tenga firma y notarización de Apple, macOS puede impedir la primera apertura.

1. Abrí la carpeta **Aplicaciones**.
2. Mantené presionada la tecla **Control** y hacé clic en **Kiosco+**.
3. Elegí **Abrir**.
4. Confirmá nuevamente **Abrir**.

Esta confirmación se realiza una sola vez para esa versión instalada.

## Actualizaciones

Las actualizaciones automáticas de escritorio quedan desactivadas en Mac hasta incorporar la firma de Apple. Para actualizar:

1. Descargá el DMG de la versión nueva.
2. Cerrá Kiosco+.
3. Arrastrá nuevamente la aplicación a **Aplicaciones** y elegí reemplazarla.

Los datos y la sesión se guardan fuera del archivo de la aplicación, por lo que reemplazar Kiosco+ no los elimina.
